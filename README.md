# Bayan - Duplicate File Finder

Bayan — это консольная утилита для поиска и вывода дубликатов файлов в указанных директориях.

## Параметры запуска

| Флаг | Описание |
| :--- | :--- |
| `-h`, `--help` | Показать справку по параметрам. |
| `-d`, `--directories` | Список директорий для сканирования (обязательный параметр). |
| `-e`, `--exclude` | Список директорий, которые нужно исключить из сканирования. |
| `-l`, `--level` | Максимальная глубина рекурсии (по умолчанию -1, без ограничений). |
| `-s`, `--min-size` | Минимальный размер файла в байтах (файлы меньше игнорируются). |
| `-m`, `--mask` | Маска имени файла (например, `*.txt` или `file*`). |
| `-S`, `--block-size` | Размер блока для чтения файлов (по умолчанию 4096 байт). |
| `-H`, `--hash-algo` | Алгоритм хеширования (поддерживается: `crc32`). |

## Сборка и установка

### Системные требования
- Компилятор C++ (поддерживающий C++17)
- CMake 3.15+
- Библиотека Boost (filesystem, program_options, crc)

### Инструкция по сборке
1. Убедитесь, что у вас установлен Boost.
2. Склонируйте репозиторий:
   ```bash
   git clone
   cd bayan
3. Создайте папку для сборки и перейдите в нее:
   ```bash
   mkdir build && cd build
4. Запустите конфигурацию CMake. Если библиотека Boost не находится автоматически, обязательно укажите путь к ней через переменную BOOST_ROOT:
   ```bash
   cmake .. -DBOOST_ROOT="C:/путь/к/вашему/boost"
5. Создайте папку для сборки и перейдите в нее:
   ```bash
   cmake --build . --config Release
